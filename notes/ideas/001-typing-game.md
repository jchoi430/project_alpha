## 한 줄 설명
아이들이 같이 노는 용도의 타자 게임. 약간 중독성은 있되 교육적이고 학교 과목과 연결되는 방향이며, 첫 번째로 만들기로 결정한 게임이다.

## 교육 목표
- 타자 연습 (메모의 게임 종류가 "타자 게임"이고 "교육적, 학교 과목과 연결"이 방향). 구체적 학습 내용(단어, 문장, 자모 등)은 메모에 없음 → 열린 질문 5.

## 플레이 방식
- 조작: 미정 (열린 질문 2)
- 한 판 길이: 미정 (열린 질문 3)
- 점수/보상 규칙: 미정 (열린 질문 4)
- 난이도 단계: 미정 (열린 질문 4)

메모에 있는 방향성만 적는다.
- 약간 중독성은 있되 교육적일 것
- 마인크래프트 스타일은 아님
- 같이 노는 용도 (여럿이 함께 하는 방식인지는 열린 질문 7)

## 화면 구성
- 메모에 화면 구성 언급 없음. 템플릿 기본 흐름(시작 / 언어 선택 / 플레이 / 결과)은 가정일 뿐이며 확정 아님. 언어 선택(영어, 한국어)이 필요하다는 점만 메모에 근거가 있음.

## 기술 구조 (메모에 명시된 제약)
- 게임당 HTML 파일 1개, 빌드 도구 없음
- 모바일 우선 (CHOMPER 방식)

## 텍스트 구분 (i18n)
- 고정 UI 문구 (메뉴, 점수, 안내): `i18n/<lang>.json`
- 설명 화면 (게임 소개, 부모용 안내): `config/<lang>.yaml`
- 지원 언어: 영어(en), 한국어(ko). 세 번째 언어는 나중에 결정.

## 비목표 (이번에 안 만드는 것)
- 마인크래프트 스타일 (메모에 명시)
- 그 외는 메모에 없음. 폭력/과금 요소는 추가하지 않는다.

## 열린 질문 (에이전트 1이 채움 — 승인 전에 사람이 답하기)
1. 대상 나이는? 메모에는 "아이들"뿐이다. (템플릿 예시값 7-10은 근거가 없어 채우지 않았음)
2. 조작 방식은? 모바일 우선이라고 했는데, 타자 게임이면 화면 키보드(모바일)와 물리 키보드(PC)를 둘 다 지원할지?
3. 한 판 길이는? (시간제 / 단어 개수제 등)
4. 점수, 보상, 난이도 단계는 어떻게 할지? ("약간 중독성"을 어떤 장치로 만들지 포함)
5. 타자로 무엇을 입력하나? (영어 단어, 한국어 단어, 문장 등) 연결할 학교 과목/학년은 무엇인지?
6. 영어와 한국어에서 입력 내용과 난이도를 같게 할지, 언어별로 다르게 할지? (한글 입력은 자모 조합 방식이라 영어와 성격이 다름)
7. "같이 노는 용도"는 한 기기에서 번갈아 하기, 동시에 대결하기, 부모와 함께하기 중 무엇인지, 아니면 단순히 아이들이 각자 쓰는 것인지?
8. 세 번째 언어는 어느 시점에 어떤 언어로 정할지? 이번 범위에는 en, ko만 포함하는 것이 맞는지?
9. "CHOMPER 방식"의 구체적 내용(파일 구조, 레이아웃 등)을 참고할 위치가 있는지? 메모에는 이름만 있음.
10. 메모에 "(games/game-ideas.md에서 옮김)"이라고 되어 있음. 원본 games/game-ideas.md에 이 메모에 옮겨지지 않은 추가 내용이 있는지 확인이 필요한지?
