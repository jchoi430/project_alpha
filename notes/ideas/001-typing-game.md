## 한 줄 설명
위에서 떨어지는 단어를 바닥에 닿기 전에 입력해서 터뜨리는 60초 타자 게임.

## 교육 목표
- 학년 수준의 기초 단어를 정확하고 빠르게 입력하는 타자 연습
- 영어: sight words 중심 / 한국어: 받침 없는 단어부터 받침 있는 단어로

## 플레이 방식
- 조작: 물리 키보드와 화면(모바일) 키보드 모두 지원. 실제 타자 연습은 물리 키보드 중심
  - 모바일에서는 기기 기본 키보드를 띄우는 입력창을 쓴다
  - 한국어는 자모 조합 중(IME composition)에는 판정하지 않고, 조합이 끝난 글자 기준으로 비교한다
- 화면: 단어가 위에서 천천히 떨어진다. 입력한 단어와 일치하면 그 단어가 터지며 점수
- 한 판 길이: 60초 시간제. 바닥에 닿은 단어는 놓친 것으로 처리 (라이프 없음, 콤보만 끊김)
- 점수/보상 규칙:
  - 맞춘 단어마다 점수 (긴 단어일수록 높은 점수)
  - 연속으로 맞추면 콤보 배수, 놓치거나 틀리면 콤보 초기화
  - 최고 점수는 `localStorage`에 언어·난이도별로 저장 (저장 실패해도 게임은 동작)
- 난이도 단계 (3단계, 시작 화면에서 선택):
  1. 짧은 단어 (영어 2~3글자 / 한국어 받침 없는 1~2음절)
  2. 긴 단어 (영어 4~6글자 / 한국어 받침 있는 2~3음절)
  3. 짧은 문장
  - 단계가 올라가면 떨어지는 속도도 조금 빨라진다

## 화면 구성
- 시작: 게임 제목, 언어 선택(English / 한국어), 난이도 선택, 시작 버튼, 언어·난이도별 최고 점수
- 플레이: 떨어지는 단어, 입력창, 남은 시간, 점수, 콤보
- 결과: 점수, 맞춘/놓친 단어 수, 최고 점수 갱신 여부, 다시 하기 / 처음으로

## 텍스트 구분 (i18n)
- 고정 UI 문구 (메뉴, 점수, 안내): `i18n/<lang>.json`
- 설명 화면 (게임 소개, 부모용 안내): `config/<lang>.yaml`
- 단어 목록: 언어별·난이도별로 분리 (예: `config/<lang>.yaml` 안 또는 `words/<lang>.json`). 언어 추가가 파일 추가만으로 되게 한다
- 지원 언어: 영어(en), 한국어(ko)
