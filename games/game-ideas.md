# 게임 아이디어 모음

작성일: 2026-11-15 (기존 대화 기록 기반 정리)

## 공통 방향
- 주 대상: 아이들 (같이 노는 용도)
- 방향: 약간 중독성은 있되 교육적이고 학교 과목과 연결된 게임. 마인크래프트 스타일은 아님
- 구조: 게임당 HTML 파일 1개, 빌드 도구 없음, 모바일 우선 (CHOMPER 방식)
- 다국어: 고정 UI 문구는 언어별 번역 파일(고정), 설명 화면은 언어별 YAML 설정 파일

## 교육 게임 (우선순위 높음)

### 1. 타자 게임 (첫 번째로 만들기로 결정)
- 이유: 가장 만들기 쉽고 아이들이 제일 많이 쓸 것 같음
- 언어 선택: 영어, 한국어 (세 번째 언어는 나중에 결정)

### 2. 수학 게임 (무료 기본 게임)
- 시작: 구구단 레이스 → 일반 사칙연산까지 확장 (예: 1+1, 100+200)
- 학년별 난이도:
  - 1~2학년: 한 자리, 두 자리 덧셈/뺄셈
  - 2학년 후반: 곱셈/나눗셈 개념 도입
  - 3학년: 곱셈/나눗셈 전체
  - 3~4학년부터: 고급 개념을 하나씩 소개
- 이후 게임: 계산이 왜 그렇게 되는지 설명

## 미니게임 포털 (CHOMPER 기반, GitHub Pages)
- 이미 만든 게임: CHOMPER (팩맨 스타일, 유령 AI, 아이템 3종, 모바일 스와이프, localStorage 최고 점수)
- 추가 예정: 스네이크, 벽돌깨기, 메모리 카드 뒤집기, 2048, 두더지 잡기, 슬라이딩 퍼즐

## 게임에 붙일 기능 (나중)
- 친구 초대: 이메일, SNS, 문자
- 아이 프로필 직접 관리, 나이 제한
- 아이 전용 대시보드: 이모티콘, 장난감 돈 수집/관리
- 언어 확장: 중국어, 일본어, 힌디어 등 (미국 거주, 여러 나라 사용자 대상)
